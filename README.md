# Boosty Video Download

Расширение Chrome / Chromium для скачивания видео с [boosty.to](https://boosty.to).

Работает только на страницах Boosty.

## Установка

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку этого проекта
5. После изменений в коде нажмите **Обновить** на карточке расширения

## Использование

1. Откройте пост Boosty с видео
2. Нажмите иконку расширения
3. Нажмите **Скачать видео**
